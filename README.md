# Amazon Backend Laboratory Work 2

## Опис проєкту

Цей проєкт є реалізацією серверної частини застосунку для платформи електронної комерції (подібної до Amazon).
Система побудована на основі трирівневої архітектури:

* **Presentation Layer** — інтерфейси для взаємодії з системою
* **Business Logic Layer** — бізнес-логіка застосунку
* **Data Access Layer** — робота з базою даних через ORM

Проєкт реалізує завантаження даних про товари з CSV файлу та збереження їх у базу даних.

---

# Архітектура проєкту

## 1. Presentation Layer

Містить інтерфейси, які описують можливі точки взаємодії з системою.
На даному етапі вони не містять реалізації логіки.

Файл:

```
presentation/api_interfaces.py
```

---

## 2. Business Logic Layer

Рівень бізнес-логіки відповідає за:

* читання даних з CSV файлу
* створення моделей товарів і категорій
* виклик рівня доступу до даних для збереження інформації

Файл:

```
services/product_service.py
```

---

## 3. Data Access Layer

Цей рівень відповідає за взаємодію з базою даних.

Використовується ORM фреймворк **SQLAlchemy**.

Рівень містить:

* інтерфейси репозиторіїв
* реалізацію репозиторіїв
* моделі бази даних

Файли:

```
data_access/interfaces.py
data_access/repositories.py
models/models.py
```

---

# База даних

У проєкті використовується база даних **SQLite**.

База створюється автоматично після запуску програми.

Файл бази даних:

```
amazon.db
```

Таблиці:

* **categories** — категорії товарів
* **products** — товари

---

# ORM

Для роботи з базою використовується ORM бібліотека:

* SQLAlchemy

ORM дозволяє працювати з базою даних через Python-класи.

---

# Dependency Injection

Зв'язок між рівнями реалізований через:

* **інтерфейси**
* **Dependency Injection**

Класи бізнес-логіки використовують **інтерфейси**, а не конкретні реалізації репозиторіїв.

Приклад:

```python
ProductService(product_repository, category_repository)
```

---

# CSV файл

Усі дані для заповнення бази знаходяться в одному CSV файлі.

Файл містить **1000 рядків**.

Структура CSV:

| name | price | quantity | category |
| ---- | ----- | -------- | -------- |

Приклад рядка:

```
phone,599,10,Electronics
```

---

# Генерація CSV файлу

CSV файл створюється окремим модулем.

Файл:

```
csv_module/generate_csv.py
```

Команда запуску:

```
python csv_module/generate_csv.py
```

Після виконання буде створено файл:

```
csv_module/data.csv
```

# Запуск проєкту

## 1. Встановлення бібліотек

```
pip install sqlalchemy pandas faker
```

---

## 2. Створення CSV файлу

```
python csv_module/generate_csv.py
```

---

## 3. Імпорт даних у базу

```
python main.py
```

Після запуску:

* створюється база даних
* CSV файл читається
* дані записуються в таблиці
